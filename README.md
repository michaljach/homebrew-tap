# michaljach/homebrew-tap

Homebrew formulae and casks for my tools.

```sh
brew install michaljach/tap/mtop
brew install --cask michaljach/tap/coffee
```

| Name | Description |
|---|---|
| [mtop](https://github.com/michaljach/mtop) | Compact terminal dashboard for system, throughput, GPU and Docker |
| [coffee](https://github.com/michaljach/coffee) (cask) | Menu bar toggle that keeps the Mac awake, even with the lid closed |
